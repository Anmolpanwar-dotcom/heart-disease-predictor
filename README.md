# ❤️ Heart Disease Predictor

A machine learning-based diagnostic tool designed to predict the likelihood of heart disease in patients based on clinical parameters. This project utilizes a supervised learning approach to provide data-driven insights for medical predictive analysis.

## 🚀 Overview
The **Heart Disease Predictor** analyzes key health indicators such as cholesterol levels, heart rate, and blood pressure to classify the risk of heart disease. It is built using **Python** and **Scikit-learn**, focusing on high precision and recall to ensure reliability in a medical context.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
* **Algorithms:** Logistic Regression (Primary), Random Forest (Evaluation)
* **Environment:** Jupyter Notebook / VS Code

## 📊 Key Features
* **Clinical Data Analysis:** Processes features like age, sex, chest pain type, resting BP, and cholesterol.
* **Exploratory Data Analysis (EDA):** In-depth visualization of correlations between various risk factors using Seaborn and Matplotlib.
* **Data Preprocessing:** Includes data scaling and handling of outliers to improve model performance.
* **Performance Metrics:** Evaluated using Accuracy, Precision, Recall, and Confusion Matrix to minimize false negatives.

## 📈 Model Performance
The model was trained on standard clinical datasets and achieved optimized results:
* **Accuracy:** High predictive accuracy on test splits.
* **Reliability:** Focused on **Recall** to ensure potential heart issues are not overlooked.
